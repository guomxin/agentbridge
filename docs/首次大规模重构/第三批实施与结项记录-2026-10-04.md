不强行统一实现：OpenClaw 保持每次尝试超时，Reference 保持 5 秒总预算；两者均不自动重放结果未知的提交。
旧新组合准入对比 13,840 组一致，中央完整 profile 投影一致。宿主版本更新为 `0.4.110`，历史 `0.4.109` 等级仍保留。

## 前端与资源交付

Workspace 拆出请求、生命周期、卡片、结果、进度、表单、技能与流解析八个模块；管理端拆出展示、生命周期、请求、弹窗四个模块。
入口仍承担页面编排，未引入框架或外部 CDN。原有三份源码截取式 Node 测试改为直接导入模块。
新增用例覆盖晚到响应、账号切换、详情乱序、流取消、同幂等键网络重试、计时器清理、图片并发读取预算和旧草稿响应。

管理端额外修复会话初始化迟到后清除新登录、同页弹窗读请求乱序覆盖，以及旧表单提交完成后影响新表单的问题。
已提交管理写请求不会因切换视图而自动重发；取消界面等待也不代表撤销后端已经接收的写入。
`.mjs` 纳入 wheel，服务器显式返回 JavaScript MIME；Workspace 模块进入资源版本摘要，未带版本的模块使用 no-store。
真实 HTTP 测试递归读取两个应用的模块依赖，核对 MIME、CSP、缓存策略和路径边界。
