# 首次大规模重构

本目录集中保存 2026-10-04 启动的首次大规模重构的评审、分批设计、实施和测试证据。
目标是在保留现有功能、业务权限和受控写入边界的前提下，降低新增系统、能力、技能和宿主的修改成本。
继续采用模块化单体，按小批次推进，每批独立验证。九月已经完成的职责拆分、发布和恢复治理是本次工作的基础。

2026-10-04 用户确认后续不再使用 Windows。本次及后续重构以 macOS 开发和本机宿主、Linux 中心服务及 CI 为维护目标，
Windows 兼容与实机验收不再作为完成条件。现行验证使用 Python 共享计划；既有 Windows 脚本和迁移证据作为历史兼容材料保留，后续按依赖逐步清理。
