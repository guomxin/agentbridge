| 问题 | 修改 |

| R1 本人日志截断 | 返回 total、returnedCount、offset、nextOffset、hasMore、truncated 和 coverage；最多每页 500 条、offset 上限 100000，保持筛选条件续取。合计仅代表返回记录；跨调用并非冻结快照，需按标识去重并核对源总量。 |
| R2 异常行 | 在分页前检查所有源行的对象结构、标识和有效日期；异常行拒绝，不静默变成空结果。真实空列表和传输错误保持区分。 |

| R4 下载期限 | 保留旧字段并增加 reportExpiresAt、downloadExpiresAt；工具说明优先展示下载入口期限。入口过期时原 report_id 续取同一报告，不重新查询；原有身份、来源、授权版本和留存期限复核不变。 |
| R5 目标定位 | 搜索说明要求分页并核实相关候选，报告已查数量、剩余范围、停止原因；分页工具继续复用，工具成功不等于目标已找到。 |
| R6 文档位置 | 明确用户授权的定位请求允许读取候选核实，返回标题、知识库、sourceUrl 和非敏感位置依据；凭据值继续脱敏。同源 URL 校验，不将仅提及地址视为已确认目标。 |
| R7 终态正文 | 收到流终态后有界核对相同会话、相同 run 的历史；只接受 stop/end_turn 的 assistant 终态，排除工具前说明及其他回合。权威历史正文替换临时前缀，用于实时、持久化和刷新；历史未到走既有恢复，不重发请求。保留合法重复段落，不重写旧历史。 |
| R8 凭据脱敏 | 共用帐密/账密、引号赋值、环境变量密钥、连接串、表格字段识别；OCR、结构化字段和元数据一致处理，表格续页保留敏感列关联。元数据说明类别、字段位置和已知模式检测边界。 |
| R9 搜索范围 | searchScope 明确 organization_public_area，不代表其他团队空间或私人知识库；保留旧 scope 枚举并同步工具目录和适配文档。 |
