# 首次大规模重构手工验收用例与简短提示词

编写日期：2026-10-05。适用基线：Release `cd9426193642`、插件 `0.4.110`。
本清单包含 44 个用例，供用户自行操作，只列提示词、步骤和预期，不设通过状态、执行日期或结果记录栏。
有问题时告诉助手“用例编号＋实际现象”即可，不要求逐项回报或提供验收截图。

## 使用方法

- 默认在 Agent Workspace 操作；管理端用例在管理控制台操作。提示词仅复制反引号中的文字，不带编号。
- 把 `〔日期〕`、`〔起日〕`、`〔止日〕`、`〔标题〕` 等替换成实际值。待办优先使用结果中的明确标识；同名时先选清楚目标。
- 日期选有真实数据的近期范围；空结果用源系统确认没有记录的范围。条数、状态、工时以当时源系统为准，不沿用历史验收数字。
- “刚才”类提示紧接对应结果发送；中间换过任务，就重新指明目标。不同用例若可能相互影响，可使用新对话。
- 写入用例默认到字段核对或授权页即停止。填写字段不等于批准业务提交；**保存 OA 草稿也属于真实写入**。
- 标明“实际写入”的用例由你选择合适测试对象并在可信授权页确认；撤销或恢复须按对应业务流程独立授权。
- 没有第二账号、相应权限、实际样本或自然故障时，可先略过对应条件用例，不必为了测试改变生产环境。

想先走一遍主要流程，可按 **A01 → A02 → A04 → A07 → B01 → B04 → C01 → D01 → E01 → F01**。
其余按模块继续；按用户当前安排，本清单暂不包含照明系统测试。

## A．工作台与页面恢复（8 项）

| 编号 | 场景 | 简短提示词／操作 | 预期 |
| --- | --- | --- | --- |
| A01 | 登录与历史 | 登录工作台，刷新一次 | 账号正确；仍处于登录状态；本人的历史消息和任务可查看 |
| A02 | 普通请求与完成状态 | `查看我的OA待办。` | 返回实际列表或明确空结果；完成后不一直显示处理中；最终答复不重复 |
| A03 | 处理中刷新 | `汇总〔起日〕至〔止日〕的OA已办和已发。`；看到已开始处理后刷新，不重发 | 恢复原请求进度，最终结果可见；同一用户消息不重复。若刷新前已完成，只验证了完成后恢复 |
| A04 | 图片链路 | 上传一张内容明确的测试图片，发送 `说说图片里有什么。`；结果出来后刷新，预览并下载原图 | 回复与图片相符；刷新后缩略图仍在；预览正常；下载文件可打开且与原图一致 |
| A05 | 附件移除与限额 | 添加两张测试图，移除一张后发送 `只描述附图。`；另一次尝试添加第五张图 | 只发送保留的图片；一次最多四张，超限有提示；撤掉的图不混入后续消息 |
| A06 | 视图与详情切换 | 在对话、任务、业务助手、端点间切换；若有两条任务，快速依次打开详情；缩窄窗口再返回 | 最后选中的页面和任务保持正确；旧详情不覆盖新详情；按钮、返回和内容可用 |
| A07 | 换号隔离 | A 账号发送 `只回复：手工验收甲。`；退出后登录 B，再回到 A | B 看不到 A 的这条消息、附件、私有草稿；A 重新登录后仍能看到自己的消息 |
| A08 | 自然掉线后的恢复 | 仅在只读请求自然断线或电脑正常休眠恢复时观察；恢复连接后刷新一次，不重发 | 能恢复原请求或说明当前状态；不把未知状态冒充成功，不诱导重复提交。没有发生故障时不强行制造 |

## B．业务读取与文件（8 项）

| 编号 | 场景 | 简短提示词／操作 | 预期 |
| --- | --- | --- | --- |
| B01 | OA 待办详情 | `打开待办〔标题〕。` | 与 OA 的标题、发起人及正文对应；同名目标先澄清，不误开另一条 |
| B02 | OA 历史日期 | `查〔起日〕至〔止日〕的OA已办和已发。` | 已办按处理时间、已发按发起时间；两类分开说明；没有查全时明确范围限制 |
| B03 | OA 通讯录／证书 | 分别发送 `查同事〔姓名〕的部门。`、`查〔证书名称〕的扫描件。`；有可下载文件时保存 | 同名人员不混淆；只返回当前权限可见资料；证书文件卡能实际下载，不能只口头说已生成 |
| B04 | 日志业务读取 | `查〔日期〕我的工作日志。` | 日志系统中的本人、日期、正文及工时对应；空记录与读取失败区分 |
| B05 | 日志库统计 | `用泰华日志库按天统计我〔起日〕至〔止日〕的日报条数和工时。` | 走当前已授权数据库；明确本人和日期口径；每天合计与总量相符；不把库内全员数据算成本人 |
| B06 | 当前数据库导出 | 紧接 B05：`按同样条件导出CSV。`；点击下载并打开 | 文件真实可用、中文可读、查询范围正确；当前导出会按查询定义重新查询，期间源数据变化可能导致数值变化；无导出权限则明确拒绝 |
| B07 | 空数据与错误输入 | 在已知空日期执行 B04；另发送 `查2026年2月30日我的日志。` | 空日期明确没有记录；无效日期澄清或拒绝，不能悄悄改为别的日期、虚构数据 |
| B08 | 语雀检索与读取 | 先 `在语雀搜索〔关键词〕。`，再 `打开〔文档标题〕。` | 命中文档可读，标题和正文对应；重名时确认知识库；Sheet/Table 若需分页能说明范围。语雀附件下载不属于现有承诺 |

当前数据库不再支持按历史 `result_id` 反查分析结果；`query_id` 用于追踪，不能当作历史读取入口。
B05/B06 以当前数据源与账号授权为准，不使用旧的个人分析七天窗口或旧下载流程作为判断标准。

## C．组合任务、取消与跨端（5 项）

| 编号 | 场景 | 简短提示词／操作 | 预期 |
| --- | --- | --- | --- |
| C01 | 双来源预览 | `把〔日期〕的OA已办和已发整理成日志草稿，只预览。` | 展示可读草稿和来源范围；不产生业务日志；不能只有“步骤完成”而没有结果 |
| C02 | 跨轮派生 | 先执行 B02，再发 `把刚才的事项整理成一小时日志，先核对。` | 承接明确来源与日期；有必要时重新核验；工时预填一小时，仍待字段核对和独立授权 |
| C03 | 空／不完整来源 | 在已知无事项的日期执行 C01；若自然出现某来源失败，再观察结果 | 完整空结果不编造工作；来源失败或未查全时明确指出，不能用不完整来源继续派生提交 |
| C04 | 取消后的任务 | 对 C02 的待办任务发送 `取消这个任务。`；之后刷新并打开旧卡 | 未提交的业务不执行；任务状态更新；旧卡不能继续推进已取消的计划。若目标不明确，应先让你选择 |
| C05 | 同一用户跨端接续 | 在已绑定同一身份的 Telegram／微信发起 `填写〔日期〕的日志，先核对。`；在工作台查看并处理卡片 | 两端对应同一目标与状态；字段填写不会被另一个端点的旧内容覆盖；授权后另一端不重复提交。无伴随端可先略过 |

## D．字段卡、OA 写流程与授权（8 项）

除 D08 外，以下用例到达授权页后选择拒绝／取消，不做真实业务提交。

| 编号 | 场景 | 简短提示词／操作 | 预期 |
| --- | --- | --- | --- |
| D01 | 日志预填与修改 | `填写〔日期〕的日志：〔内容〕，〔工时〕小时，先核对。`；在字段卡修改正文后继续 | 已提供信息正确预填；缺少项目等信息时补选；授权摘要使用修改后的值；未授权前无新增日志 |
| D02 | OA 草稿与正式提交区分 | 分别发送 `准备一份请假草稿，先核对。`、`准备提交请假申请，先核对。`；在卡中补齐真实字段 | 草稿保存和正式提交的动作、提示及授权不同；都不能在未授权时写入 |
| D03 | 出差／补签字段合同 | 分别发送 `准备一份出差草稿，先核对。`、`准备一份补签草稿，先核对。`；试一次缺必填项或结束早于开始 | 展示对应流程字段；明显无效输入被提示或拒绝，不能默默改写后提交；修正后能继续核对 |
| D04 | 会议与会议室区分 | 分别发送 `预订〔会议室〕，〔日期〕〔开始时间〕至〔结束时间〕，先核对。`、`创建并发送会议“〔主题〕”，〔日期〕〔开始时间〕至〔结束时间〕，先核对。` | 前者仅会议室申请，后者是会议创建；可选房间与实时可用情况对应；时间缺失先补问，不擅自发会议通知 |
| D05 | 撤销目标 | `撤销我的会议室申请〔申请标识〕，先核对。`；可另测 `撤销我发起的流程〔标题〕，先核对。` | 目标明确、撤销原因可核对、独立授权；已结束或不支持的对象给出原因，不替换成撤销其他对象 |
| D06 | 单条审批预检 | `办理待办〔标题〕，先让我核对。`；缺少处理意见时按页面填写 | 核对的是指定待办；先检查当前办理条件，再提供支持的操作；依据变化会提示重核对，不擅自选择审批结论 |
| D07 | 批量冻结与逐项授权 | `逐条办理〔待办一〕和〔待办二〕，先核对。`；检查候选与顺序，在首项授权时拒绝 | 只包含所选目标；每项独立核对和授权；拒绝后批次停止，不继续处理下一条 |
| D08 | 单次提交闭环（实际写入） | 选一条允许新增的测试日志，按 D01 准备；在授权页确认一次，再发 `查〔日期〕我的日志。`；返回旧授权页刷新 | 只有一次新增，正文和工时与授权一致；旧授权不再执行。若结果提示未知，先到源系统核对，不用再次发送写指令来“补测” |

D06 可按你手头样本分别覆盖：效能、差旅报销、出差、劳动续签、知识产权、加班、请假、离职、工作交接、机票、考勤确认、周报、标准协同；补签单条也可单独测试。
同一句模板替换标题即可。某一类没有待办时不需要新建业务单；支持“查看”并不代表任意状态或节点都能审批。

## E．业务助手与后台任务（9 项）

本组使用一个新建的“验收计划整理助手”；内容均为合成文字。创建草稿、提交审批等会保存技能数据，但不应调用业务系统写入。

| 编号 | 场景 | 简短提示词／操作 | 预期 |
| --- | --- | --- | --- |
| E01 | 生成私有草稿 | `做个验收计划整理助手，只整理给定文字，不补内容。`；也可在“业务助手→描述需求生成”填写同句 | 能看到后台生成任务；完成后形成自己的草稿；生成不等于已经发布 |
| E02 | 后台进度与页面恢复 | E01 生成中切到对话、刷新，再回业务助手 | 任务与草稿可恢复；不因打开页面重复生成；失败有明确提示，不能显示成功却找不到草稿 |
| E03 | 草稿编辑与乱序切换 | 修改名称或说明，点“保存新修订”；在两份草稿间快速切换 | 修订增加；内容、检查结果和按钮对应当前草稿；旧加载结果不覆盖新草稿 |
| E04 | 草稿对话试用 | 在草稿页点“对话试用”；使用样例 `整理：明天检查登录问题。` | 可见试用结果；保持“明天／计划”语义，不写成已完成；不去查询或修改真实 OA、日志 |
| E05 | 独立评测 | 按下方三个样例填写，点“启动独立评测” | 有后台进度及完成后的报告；能区分回答质量和适用性；检查失败有原因，快速试用不冒充独立评测 |
| E06 | 取消与失败重试 | 对仍在排队／执行的测试生成或评测点“取消”；仅在真实显示失败且有重试按钮时点一次“重试” | 已确认取消的任务不再保存新结果；失败和重试状态清晰。若点击前已完成，应显示实际终态，不强求取消成功 |
| E07 | 导出与导入 | 在草稿页“导出标准 Skill 文件包”，再从“导入草稿”选择该文件 | 文件能下载、导入后内容可核对；只导入方法资源，不自动发布、不扩大业务权限 |
| E08 | 申请、撤回和发布 | 选“仅自己”提交审批，再撤回一次；需要测发布时重新提交，由管理员核对当前申请后批准；使用 `用验收计划整理助手整理：明天检查登录问题。` | 撤回后不能批准旧申请；新申请绑定明确修订和受众；批准后本人可使用该版本，第二用户看不到仅自己发布的助手；审批不会授予新业务权限 |
| E09 | 可选自动沉淀 | 仅在愿意测试时开启自动总开关和本工作台范围；发送 `整理计划时，缺少日期就写“未说明”。`；查看后台候选后恢复原开关 | 能看到任务或候选分类；个人偏好不被直接当成已发布助手；不覆盖已有方法或自动发布；关闭范围后不再捕获新内容 |

E05 的短样例与表单填写：

| 测试内容 | 问题 | 表单期望 |
| --- | --- | --- |
| 回答质量 | `整理：计划检查登录问题。` | “应包含”分别填 `计划`、`登录`；“不应包含”填 `已完成` |
| 应该使用此助手 | `整理这段计划：明天检查登录。` | 选择“应该使用此助手” |
| 不应使用此助手 | `查询我的OA待办。` | 选择“不应使用此助手” |

以上是用于发现问题的样例，不保证模型一定通过；即使断言都符合，也需看一句实际回答是否保留原意。

## F．管理控制台（6 项）

| 编号 | 场景 | 简短操作 | 预期 |
| --- | --- | --- | --- |
| F01 | 登录、导航与筛选 | 登录，打开总览、用户与令牌、系统会话、操作记录、链路、多端任务；搜索一个存在的关键字再清空 | 页面可读；筛选与清空有效；任务、操作、可信交互的关联和状态不矛盾；“上次确认有效”不被描述为实时登录保证 |
| F02 | 连续切换与刷新 | 快速切换两页，连续刷新；有多条记录时快速依次打开两个详情 | 最后选中的页面保持正确；旧响应不覆盖；刷新按钮不会一直禁用 |
| F03 | 弹窗归属与取消 | 打开用户能力或数据库能力弹窗，修改选择后取消；再打开另一用户的弹窗 | 取消不保存；第二个弹窗始终显示第二用户；旧请求、旧提交错误不能覆盖新表单 |
| F04 | 助手审批依据 | 打开 E08 的新申请，查看修订、使用范围、方法检查、评测和差异，再决定是否批准 | 与申请时固定的修订和受众一致；不能把后来改动的草稿当作原审批内容；未复核时不能冒充已复核 |
| F05 | 只读审计员 | 使用已有 auditor 账号浏览用户、数据库与审批详情 | 能看授权范围内的管理元数据；不能保存授权、创建令牌或批准发布；不展示凭据及业务私有正文 |
| F06 | 授权即时生效（条件用例） | 用专用测试账号，暂时移除其某数据源的导出权限；用原登录会话请求导出，再恢复原配置 | 权限变动无需换 Token 或重启；撤销期间不能导出；恢复后可发起新导出。授权版本变化后旧文件不会因此复活 |

F06 只改选定测试账号的单项权限，并恢复原值；不使用正在依赖该权限处理工作的账号。

## 判断与反馈

页面显示“完成”后仍要看实际结果：读取以源数据为准，写入以源系统回读为准，文件以打开后的内容为准。
自然语言没有正确理解但最终换句话成功，原来的问法仍可以作为问题反馈；不需要改提示词来迁就实现。

你发现问题后，可以直接说：`A04：刷新后图片不见了。` 或 `D04：预订会议室却出现创建会议。`
本文件不维护测试是否通过；既有自动化与发布证据仍保留在[结项记录](./第三批实施与结项记录-2026-10-04.md)，不因生成本清单而新增人工验收结论。
