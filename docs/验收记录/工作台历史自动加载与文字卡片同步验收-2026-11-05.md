# 工作台历史自动加载与文字卡片同步验收

## 范围与原因

用户反馈：刷新后向前查看聊天时，旧查询文字已经出现，对应结果卡却看不到；希望上滑自动加载，文字和对应时间范围的卡片一起呈现，无需反复点击历史按钮。

2026-11-05 生产 Chrome 只读观察：xinguomao 首屏 8 张终态卡，经历史按钮依次恢复至 32、64、96、128、161 张。记录未因十分钟选择窗口过期而删除。现有入口虽然统一，中央文字每页 500 条、任务每页 32 项且按更新时间分页，仍与按创建时间排列的卡片范围脱节。

本次预期：首屏与历史页共用有界、按创建时间稳定排序的文字和任务流；上滑接近顶部时串行加载一页，整页读取成功后共同呈现并推进游标；刷新自动恢复账号绑定的历史阅读锚点，失败提供重试。保留输入草稿、展开状态与阅读位置，不因程序滚动连续扫完整个账本。

涉及模块：任务存储的只读历史查询及必要索引、Workspace BFF/HTTP、历史与滚动控制、隔离验收夹具及回归测试。不调整全局布局、依赖、业务写流程或材料期限。

安全边界：实时主体和权限核验、账号切换取消、独立 SSE 水位、投影响应顺序及不可访问退卡继续生效；浏览器保存阅读偏好，不保存操作授权或结果载荷。OA 十分钟、聊天图片七天、数据库报告二十四小时和下载入口十分钟规则不变；历史读取不触发准备、授权、提交或未知结果重放。

## 验收场景

- 超过 140 个任务及 200 条消息交错；任务创建很早但最近更新、同时间戳、纯文字和纯任务、长文本及折叠卡；同一时间范围没有只见文字不见卡，逐页无重漏。
- 首屏、连续上滑、刷新后恢复旧锚点、无存储权限、空历史及读完；加载提示出现和消失，内部滚动、输入框及展开状态保持；桌面和窄窗口截图与边界测量。
- 并发滚动只读一页；网络失败重试、认证和权限变化、账号切换取消；失败不推进游标、不循环重试、不显示旧账号数据；新消息与 SSE 不被历史游标跳过。
- OA 已过期仍只读展示；图片/文件到期占位与新加载行为兼容；合成账本业务写入及授权消费均为零。
- 先完成定向回归和隔离 Chrome 页面验收，再固定干净候选执行 Full、制品检查及正式发布门禁；发布后复验生产受影响页面，独立 CI 完成后集中收尾。
