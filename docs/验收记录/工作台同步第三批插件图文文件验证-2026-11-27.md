# 工作台同步第三批插件图文文件验证（2026-11-27）

## 范围与原因

对应 D08、D14。用户要求同轮图文、caption、公开终答和文件两端可理解，按原件独立确认；部分成功不重复，未知不以链接变相再发。开发基线为第二批集成提交 `15bb1ff0`，使用独立工作树，不修改第一批固定候选或真实 Gateway。

已确认 OpenClaw 旧出站将多张图片放入一个 timeline_message，先整体下载再逐张发送；任一失败会转发整组图片链接，已发送原件可能重复，未知发送也可能走链接后备。业务文件路径只有内存去重，并保留发送循环及链接后备，不能作为新逐件可靠协议的依据。反向 after-event hook 原本只发布文字，未冻结原生媒体元数据与受控原件引用。

预期复用第二批原身份、逐件 delivery/attempt、issue/begin/ack 和本地真实发送回执。中央统一媒体授权/受控引用由共享实现负责；插件仅使用宿主私有协议，不从模型或 caption 解析下载链接，不把原业务 CSV 变成普通上传媒体。反向仅观察已登记本人私聊的官方 SDK 原始媒体元数据，保留 caption 与附件顺序，先保存原件与请求摘要再补账；不另起 poller 或第二次模型任务。

## 安全与验证边界

- 不碰真人文件、真实 poller、生产 offset/state、浏览器或真实 TG 发送。
- 明确验证原主体/端点/当前配对、原件摘要、原始日期及期限；撤权/到期不产生新保存或发送。
- 逐件发送只有匹配原 Bot 路由和 chat 的真实 SDK 回执才记 sent；发送未知、缺回执及ACK丢失恢复不重复发送。
- 合成用例覆盖纯图、caption、多图顺序、失败/未知/部分成功、同附件不同 caption、同caption不同附件、Unicode、同键异载荷、超限及受保护产物不降级。
- after-event hook 不是平台确认之前的事务边界；不得用媒体补账功能宣称解决原生SDK确认前的崩溃窗口。

## 实现与隔离证据

出站领取显式协商 `include_workspace_media_v2`，每件使用中央固定的 `deliveryId/attemptCount/itemIndex/itemCount/pairingRef`，复用原 `issue → begin → ack` 持久回执。插件校验原件类型、尺寸、SHA-256、原期限和原私聊路由；仅使用中央返回的原字节。实际 SDK 要求 `forceDocument` 位于发送上下文顶层，不能仅放在 payload；本次同时提供精确本地目录和只允许该原文件的 `mediaReadFile`，避免中途磁盘内容变化替换已授权字节。图片不经 `sendPhoto` 转码。

反向采用中央 `telegram_media_source` 冻结原身份、消息编号和秒级 UTC 日期，随后对官方 SDK 本机 `media/inbound` 原件进行有界读取并持久保存分块。每件独立 `media_append`，caption 不参与附件身份。纯附件也进入观察钩子；URL、远端 staging、越界、未知类型、超量和到期分别拒绝读取或形成固定不可用说明。读取拒绝符号链接、外部路径、非私有媒体目录及他人可写文件；兼容 SDK 在 0700 目录内保存 0644 文件的实际策略。正常回执、未知中央回应、重新启动和撤配后的旧回执恢复均只使用原身份，不重新登记端点。清理只删除插件自己的字节分块和临时出站文件，不删除 SDK 原入站材料。

业务产物继续沿原任务、原签发下载和受保护 CSV 权利取得字节，未纳入普通上传媒体。Telegram 原产物增加独立持久发送边界与原报告补账；每次平台调用关闭透明重试，只有结构化 429 可进入新的本地 attempt，最多三次。发送未知不改发链接、不重新上传；已有真实回执优先于 SDK 后续记账异常。原报告保持兼容的 `failed + TELEGRAM_DELIVERY_UNKNOWN`，插件整体报告区分 `unknown/unknownCount`，用户摘要明确“送达结果未确认，不会自动重发”；中央与 Workspace 的对应展示由集成修改同步处理。

本轮收敛与复核记录为 2026-11-27 13:07–13:26（北京时间），与共享中央开发并行。联调发现本地测试错误地把附件引用假定为 UUID，实际中央使用 43 字符不透明标识；另一次严格校验误把 SDK 文件要求为 0600，实际是 0700 目录内 0644 文件。均按实际契约修正并新增回归、重跑贯穿。6 MiB 边界另检出分组 Base64 正则导致 V8 栈溢出，改为有界字符检查与原字节 round-trip，并覆盖 Unicode 文件名。此前缺少真实中央反向合同实例造成这项返工，不是放宽校验。
