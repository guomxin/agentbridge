# Skill 按任务目标选择：设计与验收

## 改动范围

- 将选择规则集中在宿主 `business-skills.js`：先判断任务目标，再判断是否需要 Skill 提供的方法、判断标准或流程约束。
- 用户明确指定且适用的 Skill 优先加载；未指定时允许直接使用能够明确完成任务的工具。
- Skill 加载与原子工具/持久计划的执行路径独立。独立任务不能用历史加载记录代替本轮绑定；已有任务续办沿用原绑定。
- 通用 Skill 加载接口及 OA 列表工具不包含 OA 查询例外、关键词匹配表或场景路由分支。
- 五个 Skill 的目录描述统一表达任务目标、方法和产出，目录与正文 frontmatter 保持一致。权限、授权和执行校验未改动。

## 验收边界

本次验收覆盖五个 Skill 的选择、加载、卡片关联和代表性结果交付，以及最终公共规则的显式选择、普通查询和自动选择回归。没有授权提交 OA 审批或日志；两次办理准备任务均已取消。权限不足、停用、撤销和跨用户隔离通过自动化测试验证，没有为浏览器验收临时改动真实用户权限。

选择仍由模型根据统一规则和目录描述判断，不是确定性分类器。本次不承诺所有自然语言表达都得到唯一相同选择；保留了阶段总结/时间追踪及会议室查询的实际歧义记录，也未将案例分析的每条业务结论作为本次逐条准确率验收范围。
