## 实际改进

| 场景 | 本次行为 |
| --- | --- |
| 改了处理方法，还没保存 | 显示“有未保存修改”，暂停评测和发布；试用按钮变为“保存后试用” |
| 保存后立即试用 | 先确认保存成功，再带入草稿 ID、新修订号和所选模式；保存失败或期间文字继续变化时保留输入，不进入错误修订的试用 |
| 预览已验证，填单尚未验证 | 分别显示每个模式的当前修订证据，只勾选有输出样例的模式提交；旧修订、旧内容哈希及仅触发评测不能充当本次输出证据 |
| 候选准备覆盖已有草稿 | 先显示方法、适用范围、模式依赖、参考资料及必读清单的新增、修改和移除；点击后使用查看差异时的修订号，版本变化会报冲突 |
| 助手超过候选数量上限 | 先排序再截取；完整名称或独立 ID 优先，其他按名称、简介、适用场景、输出描述的文本重合排序；“不适用”文字不增加相关分数 |

服务端额外返回当前修订完整的 `tested_profiles`，避免样例历史只展示最近 30 条时漏掉早期有效模式。后台任务刷新保留按任务 ID 展开的候选；采用中的同一候选跨刷新共用请求锁。候选排序是轻量确定性规则，不决定权限或最终适用性，没有引入向量库、训练服务或新的工作流框架。
