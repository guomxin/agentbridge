# 工作台宿主任务与 Telegram 同步隔离

## 问题与验收范围

用户在第一账号选中 OpenClaw 时看到来自 NanoBot 的“工作台任务”，并在原 OpenClaw Telegram 端看到了 NanoBot 网页对话。此前上线验收核对了新 Bot 的正向收件、个人身份和运行归属，遗漏了原 Bot 的投递账本以及切回 OpenClaw 后的任务卡。本次核对 Workspace 当前面板、任务检索、活动派发、历史与实时流、聊天镜像和终态通知，按主体、实例和端点分别验证。宿主显示名改为 NanoBot，保留原实例及个人默认设置。

14:20 起在生产只读核对，第一账号的网页默认选中 OpenClaw 时确实出现 NanoBot 任务。此前 14:03–14:04 的 NanoBot 网页测试中，两条用户消息及两条助手回复各自被排入原 OpenClaw Telegram 端的聊天同步队列，四条中央记录均已确认。在中央全部可关联的留存聊天投递中，第一账号从 NanoBot 网页误发原 Bot 共四条，第二账号为零；两账号反向记录、投递主体不一致记录均为零。四条入队时间为北京时间 14:03:49–14:04:32，收到发送确认的时间为 14:03:52–14:04:35。跨端任务通知与此例无关。正式下游操作、授权记录、已送达历史及现有账号登录按原规则保留。

验收包括同一账号两个宿主、同类型不同实例、两个账号、历史翻页、切换宿主后的旧任务续办、存量待发排除和同实例的正常渠道投递。真实复核使用无业务内容的测试消息，并检查两个 Bot 的投递差异。

## 根因与隔离实测

中央按个人主体枚举所有支持推送的端点，未核对消息源和目的端属于同一实例。原 OpenClaw Gateway 的四条成功回执与中央账本的四个投递一一对应。任务卡来自第一账号一次成功结束的 NanoBot 会话状态只读查询。原任务只记了创建事件，未获得终态，15 分钟后的孤立任务维护将其标记为过期。其间任务视图按主体读取，切回 OpenClaw 仍能看到来自 NanoBot 的任务。

14:29–14:33 使用 Chrome 扩展在隔离页面给两个宿主各放一条不同的历史消息和一张进行中任务卡。第一账号两个标签页分别固定在 OpenClaw、NanoBot，两页刷新后各自只显示一张卡、一条消息和正确的计数。另一页修改默认值后，旧页尝试发送被拒，输入草稿保留，重新载入后标题、消息、卡片的宿主一致。第二账号只见自己的测试数据。并发验收的首次运行仍加载旧版静态文件，重新启动候选进程后复验通过。

隔离 SDK 探针中，成功查询会话状态新增中央任务 0 个。获准的数据库读取和被拒绝的读取分别以中央回执收敛为成功、失败。存量已过期的任务保留原状态。Telegram 的隔离验证覆盖同实例投递、另一同类型实例、存量待发、发送前撤权、租约和已确认的历史回执。NanoBot 原私聊的终态只发送一次，普通网页对话未开启向该 Bot 的全量镜像。

首次 29 项兼容复验暴露旧调用可省略 Web `account_id`：更新端点时会抹掉已登记的账号。已改为复用原 Web 绑定并核对主体和会话，探针使用实际目录绑定。完整重跑 29/29 通过。14:37–14:41，首个候选 `5a9517f56f2d` 的 Full 在 Python 阶段发现十例失败，未进入生产事务。七例反馈测试只带主体，现改用真实入口所传的完整工作台账号，并增加缺失账号拒写断言。另三例涉及旧宿主原端点通知及 Telegram 端点身份变化，纳入新候选复验。

14:44–14:49，候选 `1e57c32397c9` 的 Full 十阶段通过，Python 4,250 项通过、4 项按既有规则跳过，Workspace Node 687 项、OpenClaw 400 项通过，wheel 安装校验和独立 SDK 29 项兼容验证通过。隔离 Chrome 两页并排时，OpenClaw 的原任务通过实时事件变为已完成、计数从 1 降至 0，同账号 NanoBot 的原任务和计数 1 均保持正确。

正式发布首先发现 Mac Gateway 实际加载的旧固定插件归档版本为 `0.4.132`。按手册从候选生成只读归档，逐文件校对 58 个文件，只替换该插件加载路径，冷/热预热及运行时核验确认 `0.4.133`。随后 NanoBot 版本切换遇到 launchd 停服竞争：14:55:25.752 开始重载同名 worker，旧进程于 14:55:26.697 才完成退出。首次自动恢复也遇到同一竞争，独立正式回退已成功恢复前一 NanoBot 版本、三个受管作业和原目录名称。保留所有失败及回退收据。此时中央版本为 `1e57c32397c9`，Mac NanoBot 在 `1ace31474938`。
