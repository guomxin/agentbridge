# 插件发布维护恢复修复

本次问题：原生 `host stop` 会 disable 和 bootout Gateway，但 `publish` 的条件重启只会 kickstart，不能恢复已卸载作业。新插件与旧中央的协议窗口也不能当作已验证的运行状态。

范围限定为 OpenClaw 换加载归档前的短维护：受管停止生成绑定固定候选、原宿主授权、原 plist、原配置和目标配置的私有收据；正式发布明确引用该收据，才可在确认作业未加载、原进程退出、监听释放且原输入不变时恢复。普通 stop、restart、人为禁用及其他宿主行为保持原义。配置仍由操作者备份后原子替换，发布不修改配置，不读取业务正文或重放投递。

验收使用隔离临时目录和服务管理替身，覆盖成功恢复、未提供收据、原先已禁用、未知 launchctl 状态、其他监听、安装文件字节或所有者变化、候选与目标配置变化、重复启动和中断恢复。额外仅只读核对已安装 plist 的字节、权限与启动参数。此项没有实际启停生产作业，实际发布与原 Bot 入站复验由正式发布窗口完成。

定向首轮 88 项通过。实际已安装 plist 为当前用户所有、0600，参数为固定官方 SDK 的 `gateway run --bind loopback --port`；未设置 reload 环境开关。原配置未关闭 SDK 的默认自动重载。当前 macOS `print-disabled` 使用 `enabled/disabled`，专项同时覆盖该格式、`true/false`、无覆盖项的默认值与未知格式拒绝。源配置和所有生产状态保持不变。
