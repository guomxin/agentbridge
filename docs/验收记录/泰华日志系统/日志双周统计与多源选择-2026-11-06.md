## 实现与候选前验收

- 现有统计授权支持 `baseline_start_date`。一次参数化 SELECT 在同一来源返回两周各六项指标、本期减基期的差值和百分比。基期为零时百分比为空。CSV 继续复核导出和原查询权限，有限数值类型的负差按数值写入，公式形态的文本保持转义。
- MCP 和查询 CLI 在省略源时解析当前账号所有启用且获准的来源。有多个源时返回 `DATABASE_SOURCE_SELECTION_REQUIRED` 和 `select_source`，即使只有一个源支持目标操作也要明确选择。文件下载复用同一规则并校验所有者及源版本。宿主目录、规划说明和注册版本同步到 0.4.125。
- 18:04 至 18:14（北京时间），实现与隔离准备并行。独立 PostgreSQL 18.6 WebAssembly 引擎用合成表执行候选 SQL，全部范围、含下属部门、项目和关键词、仅周报、两期均空共 5 组，每组 6 项指标及日期与独立预期一致。原生联合定向 70 项通过，1772 子测试通过，包含日期边界、负差、零基、下载、撤权、宿主目录和实际 MCP 入口。
- 隔离 Workspace 经过真实 OpenClaw 2026.7.1、候选插件、认证 MCP 和 Workspace 回复。模型工具调用及业务数据为合成，四条请求分别为单源比较、自由 SQL 拒绝、双源未选、明确西区。Chrome 扩展在两个合成账号检验了实际页面。单源日报从 2 条到 3 条、登记工时从 5 到 9；多源先提示选库，指定西区后登记工时从 23 到 9。两次拒绝均未发起下游查询。
- 首轮验收夹具的模拟模型误把宿主附加规则里的“自由 SQL”当成用户意图，四个问题都触发自由 SQL 拒绝。按用户消息修正夹具后重新启动完成上述验证。数值导出另补了模拟驱动返回 Decimal 的下载读回，验证负差和负百分比留作数值，基期为零时单元格为空。
