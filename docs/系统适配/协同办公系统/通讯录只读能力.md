# OA 通讯录只读能力

## 一、能力边界

本能力包读取当前用户在 Seeyon OA 中有权查看的通讯录，不新增、修改或删除组织、人员、
联系组和私人联系人。所有调用复用该用户的中心 OA 会话，并要求独立权限
`oa:read:addressbook`；拥有普通流程读取权限 `oa:read` 不会自动获得通讯录权限。

OA 已显示为 `******` 的电话继续按原样返回和导出。AgentBridge 不尝试绕过 OA 权限、还原
掩码或合并其他用户的通讯录数据。

## 二、公开能力

| 能力 | 用途 |
| --- | --- |
| `oa.addressbook.organization.tree` | 查看当前可见组织和部门树，可按名称过滤 |
| `oa.addressbook.department.members` | 查看指定部门成员，可选择是否包含子部门 |
| `oa.addressbook.person.search` | 按姓名或全部可见字段查找组织人员 |
| `oa.addressbook.person.get` | 用搜索结果中的 `person_ref` 重新核对一个人员 |
| `oa.addressbook.group.list` | 列出私人、个人、系统和项目组 |
| `oa.addressbook.group.members` | 查看指定组的成员 |
| `oa.addressbook.private_contact.search` | 查找当前用户的私人联系人，可限定私人组 |
| `oa.addressbook.private_contact.get` | 用 `contact_ref` 重新核对一个私人联系人 |
| `oa.addressbook.export` | 把人员搜索、部门、组或私人联系人结果导出为 CSV |

人员详情以 OA 通讯录列表实际开放的字段为限，包括姓名、人员编号、部门、岗位、办公电话和
手机号码；私人联系人按 OA 页面返回姓名、单位、职务级别和电话。系统没有开放的个人卡片字段
不会被推断或补造。姓名重名时智能体应列出候选，不得自行猜选。

## 三、查询和导出规则

- 单次列表和导出最多 500 行，返回 `source_total` 和 `truncated` 说明是否被截断。
- 部门和组必须先从树或组列表取得稳定 ID，再查询成员，避免只凭同名文本选错目标。
- `search_type=name` 只按姓名查询；`search_type=all` 使用 OA 页面支持的综合字段查询。
- CSV 采用 UTF-8 BOM，防止中文乱码，并对可能触发电子表格公式的单元格做安全转义。
- 导出文件进入 Task Hub 文件交付，可在短期下载链接过期后按原筛选条件重新生成当前数据。
- CSV 不包含内部人员 ID、联系人 ID、`person_ref` 或 `contact_ref`。

## 四、会话和错误语义

会话有效时直接读取；会话过期时返回可信登录交互，登录成功后按只读恢复规则继续原请求。
组织树、成员表或分组树结构与已验证契约不一致时失败关闭并返回契约错误，不退回任意 DOM
扫描，也不产生写操作。

## 五、实现位置

- 页面契约与解析：`agentbridge/adapters/seeyon_addressbook.py`
- 中央能力注册和调度：`agentbridge/adapters/seeyon_central.py`
- MCP 工具与权限：`agentbridge/mcp/central.py`
- CSV 治理与重新生成：`agentbridge/core/report_exports.py`、`agentbridge/core/central_service.py`
- 只读契约探测：`scripts/inspect_oa_addressbook_contract.py`

## 六、试点授权状态

2026-08-26 已为第一用户正式 Token 增加 `oa:read:addressbook`，并在真实 OA 上通过组织查询验证。
新 Token 生效后才撤销被替换的旧 Token；第二用户 Token 未修改。自然语言中的“相关部门”可能是
语义关系，而 OA 组织接口当前执行名称和路径的字面过滤；字面无匹配应返回空结果，不应误报为
权限不足。
