## 实现范围

新增 `taihua.analytics.personal.summary` 和 `taihua.analytics.result.get`，MCP 名称分别为 `taihua_analytics_personal_summary`、`taihua_analytics_result_get`。两者均要求 `taihua:read` 与 `taihua:analytics:read`；原 Token 不自动获得新 Scope。管理台和 Token CLI 已提供显式选择。

summary 四个必填字段为 start_date、end_date_exclusive、log_type、group_by；只接受 DAILY、none/day 和 1—7 天的半开日期窗口。返回登记工时、日志数、有日志人日、未关联项目统计、每日汇总和数据时间。小时使用 Decimal 字符串，零分母为 null。统计不代表考勤或绩效。

```json
{
  "start_date": "2026-08-31",
  "end_date_exclusive": "2026-09-07",
  "log_type": "DAILY",
  "group_by": "day"
}
```

本人身份通过受控会话的 principal 核验，并绑定不可由模型修改的数据库人员 ID。本人 API 与团队仅本人分页必须有一致的完整候选集合；缺 total、重复 ID、筛选不符、达到 500 条或接口无权限都拒绝统计。空结果也必须有明确总量证明。

固定 SQL 同时约束本人 ID、API 可见 ID、日期和 DAILY，不读取正文。只读、REPEATABLE READ 事务内执行行投影和聚合，API 前后复核核心字段。数据库事务在后验 HTTP 开始前回滚并关闭。created_at 按已验证的秒精度比对，数据库原时间保留在加密证据中；updated_at 不套用 API 空值。

## 中央治理

- 初次调用、历史读取及幂等复用都重新检查当前 Token、数据源准入、会话版本及可见范围。数据库认证失败不会触发日志系统登录。
- Operation、通用任务读取只返回受保护结果引用；业务数字和行投影保存在独立用途加密仓库。跨用户、策略停用或可见集合变化后拒绝历史读取。
- 会话 authority_generation 在状态变化和主体重绑时递增，保活不递增。numeric principal ID 变化会隔离会话。
- Task Hub 记录 identity、visibility、query、verify、deliver 阶段；Workspace 沿用现有进度呈现。登录续办由中心账本去重；反馈消息不再次持久化分析数值。取消等待登录的分析任务后不续办。
- MCP 断开和任务取消传递取消信号；SQL 执行期间调用驱动取消，等待执行器关闭连接后再结束取消状态。每用户最多 1 个、数据源最多 2 个分析，单调用最多 60 秒。
- 同一中心 home 使用 OS 文件锁保证单进程执行，运行实例不能使用不同 home 同时启用同一数据源。多实例/分布式配额尚未实现。
- 成功结果有效期 7 天。现有中心治理周期清理过期密文及引用；服务停机期间不运行清理，恢复时清理。已清理的引用按不可访问处理。结果有效期内被撤销权限的快照不再提供业务读取。
- 一期 B 已实现：两窗口比较使用两个 summary 加 taihua_personal_compare.v1 的三步 v2 持久计划，只持久化受保护引用。单窗口每日 CSV 使用 summary → report_export → report_download 调用链，不编造导出转换或把导出塞入比较计划。

## 配置与启用

在中心服务的 OS 运行身份下安装可选依赖。禁用状态不导入 psycopg，也不连接数据库：

```powershell
python -m pip install ".[postgresql]"
python -m agentbridge.analytics.admin --home <中心数据目录> configure
python -m agentbridge.analytics.admin --home <中心数据目录> check
```

configure 隐藏交互读取数据库密码并加密保存，生成默认关闭的 `analytics/source.json`。密码不能放入命令参数、source.json 或 Git。该配置命令会提升 credential_version 并关闭数据源；轮换完成后需重新验收启用条件。

check 仅查询元数据和带空 ID 集合的固定 SQL，不读取业务行、不执行写入探测。它校验必需列、主键、事务隔离、表/列 DML、TEMP、序列 USAGE 和特权角色。认证表读取范围仍由数据库所有者审查并收敛。默认只读事务选项由执行器强制设置；该运行时检查不代替管理员对角色默认配置的审计。

管理员完成核验后，在受限 source.json 中配置：

- `admitted_subjects`：已完成真实验证的中央 user_subject 明确列表，不支持通配符；
- `privileges_reviewed: true`：记录权限收敛及认证表范围审查已经完成；
- `single_instance: true`：部署确实只有一个启用数据源的中心实例；
- `enabled: true`：完成以下真实验收后才设置。

sslmode=disable 只允许原有精确目标 10.10.50.101:35432/sisyphus；其他目标必须采用 verify-full，不自动降级。设置地址及凭据仅允许管理员，本期工具不接收连接参数。数据源配置在调用前后读取，配置变化会中止交付。

2026-09-10 DBA 已将账号收敛到 analysis 下五个脱敏视图，撤销 public 业务表直接读取、TEMP 和序列权限。执行器固定读取 analysis.work_logs 的八个统计字段，不依赖登录 search_path；public.work_log 仅通过 pg_catalog 核验原始主键元数据，不读取底表。字段契约、API 前后可见性核验和逐行对账继续保留；五视图可读不代表新增团队、项目或正文分析能力。新版已在生产源库通过 strict 空查询预检及两用户历史验收样本对账；正式服务已发布 007c17004db2 并恢复 strict，账号、密码和两用户准入不变。

## 一期 B：周期比较与受控导出

一期 B 增加 `taihua_personal_compare.v1` 确定性转换、`taihua.analytics.report.export`、`taihua.analytics.report.download`。后两者同时要求 `taihua:read`、`taihua:analytics:read`、`taihua:analytics:export`，MCP 名称将点替换为下划线。

比较使用 v2 持久计划，结构固定为两个 `personal.summary` 和一个比较转换。分别将两个来源的完整输出引用通过 `baseline`、`current` 绑定至转换，pointer 为空字符串；`allow_unequal_windows` 为必填布尔值。目录附有可直接改日期使用的实例，两个半开窗口各最多七天。不能加入写入、其他转换或把模型提供的明文数值作为来源。源步骤、操作记录、计划投影及事件只包含受保护引用，指标仅在认证的结果读取中解密返回。

比较输出登记工时、日志数、登记人日的差额和变化率。变化率为差额除以基期绝对值，基期零返回 null 及原因。等长窗口比较总量；非等长窗口只有显式允许后才比较每自然日均值。每个来源保留自己的查询时间和口径，不宣称跨窗口为同一数据库快照。读取比较结果时，两份原始结果都必须仍有效并通过当前本人可见性核验；任意一份过期或权限变化则拒绝整份结果。

导出步骤：先生成 `group_by=day` 的本人汇总，调用 `taihua_analytics_report_export(result_id)`，再以其 `report_id` 调用 `taihua_analytics_report_download`。CSV 为 UTF-8 BOM，仅含每天登记工时、日志数、人日、未归项目工时和口径；不含日志正文、联系人或凭据，所有单元格复用公式注入转义。只有总量、没有每日分组的旧结果不能导出，请重新请求每日汇总。

下载引用有效十分钟，加密文件保留最多二十四小时且不超过来源结果寿命。重新签发时使用新的 export 请求/幂等键，重新核验源结果；旧幂等键不会延长旧引用。生成、缓存命中、重新签发和每次下载均验证当前身份、独立 Scope、数据源启停、会话版本、当前可见性及来源 TTL。

下载采用认证 MCP 文件响应或 Workspace 已登录下载入口，**不发布匿名或仅凭签名即可读取的 URL**。这是对详细设计中链接交付形式的具体收敛，十分钟下载引用替代签名链接。OpenClaw 复用现有私聊文件附件交付，将本次已认证响应写入宿主媒体存储后发附件，并移除给模型的重复 base64 内容；失败不会降级为公开链接。Workspace 复用任务文件卡，链接仅指向同源 `/api/analytics/reports/{report_id}/download`，每次下载同时校验网页登录身份、原导出授权的当前 Scope、来源结果与应用会话；不能跨用户读取或在原授权撤销后继续下载。其他 MCP 宿主可读取返回的 `file.content_base64` 保存 CSV；已经下载给用户的副本不属于中央文件 TTL 或撤权删除范围。

新安装的数据源默认关闭；当前生产数据源已启用，仅准入 guomao、lishiyu。现有数据库五视图授权不会自动扩大应用准入或开放新分析能力。
