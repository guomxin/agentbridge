# 苹果系统原生维护入口

当前代码维护目标为 macOS 开发及 OpenClaw 宿主、Linux 中心服务与 CI。命名统一后的 Python 分发包、导入模块和主命令为 `agentbridge`，旧 `bscli` 命令仅兼容到 `0.3.0`。本页描述新版本操作合同，实际部署状态以[实施记录](../验收记录/命名统一与平台收敛实施记录-2026-10-09.md)为准。

## 环境与验证

使用 Python 3.12 以上创建独立 `.venv`，从可信仓库安装本项目，不从公共索引猜测同名包归属：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install 'setuptools>=77' pytest pytest-xdist
.venv/bin/python -m pip install --no-build-isolation -e '.[database-analysis]'
scripts/agentbridge-native validate --test tests/test_native_maintenance.py
scripts/agentbridge-native validate --full
```

入口也接受 `AGENTBRIDGE_TEST_PYTHON`。默认日志为 `~/.local/state/agentbridge/maintenance/`，可通过子命令前的 `--report` 指定仓库外私有路径。验证子进程使用临时会话密钥，不继承生产密钥。Full 需要干净、已提交的候选，收据绑定提交、环境、各阶段结果及 wheel。

## 宿主配置

外置 `agentbridge.mac-host.v1` profile 使用权限 0600，必需路径包括 `node`、`openclaw`、`stateDir`、`configPath`、`envFile`、`runtimeDir`、`caCertificate`；`tunnel` 包含 `host`、`user`、`identityFile`、`knownHostsFile`、`remotePort`。路径须为已核验的本机路径；状态和秘密不放在代码仓库内。

`preparationOnly=false` 只用于已审核的正式 profile。宿主固定 OpenClaw 2026.7.1，Gateway 认证不可关闭，保留 `stuckSessionWarnMs=30000`、`stuckSessionAbortMs=120000`。dotenv 按字面值读取，不执行 shell 展开。

## 宿主登记与授权

日常发布不再读取历史工作站迁移包。新授权绑定当前机器及登录用户、profile SHA256、状态目录和 CA 文件 SHA256，使用 `agentbridge.host-authorization.v1`。更换机器、profile、CA 或状态目录后必须重新登记。

在私有 `agentbridge.host-ownership.v1` 记录中填写：

- `bindings`：`hostId`、`profileSha256`、`stateDir`、`caSha256`，与审核配置的实际值一致。
- `checkedAt`：含时区的实际核验时间；登记时要求在过去 24 小时内。
- `gatewaySingleOwner`、`tunnelSingleOwner`、`identityBindingsReviewed`：只在核验唯一宿主、服务器反向端口和身份绑定后填写 true。

这些是本机操作人员的核验记录，不是远程数字证明。不能为了通过门禁预填 true；日常启动仍检查配置绑定和监听所有权。记录与授权文件都必须位于仓库外，属于当前用户，权限 0600，不允许文件符号链接。

可用原生 `host review` 输出 bindings 和现场只读观察，填写核验记录后登记：

```sh
scripts/agentbridge-native host review --profile /私有目录/mac-host.json
scripts/agentbridge-native host register --profile /私有目录/mac-host.json \
  --ownership-evidence /私有目录/ownership.json --destination /私有目录/authorization.json
```

`register` 不启动进程，不覆盖已有授权文件。旧迁移证据和加密材料保留为历史原件，不转换或修改其内容。

## 生命周期

```sh
scripts/agentbridge-native host render --profile /私有目录/mac-host.json --destination /私有目录/plist-review
scripts/agentbridge-native host status --kind gateway --profile /私有目录/mac-host.json
scripts/agentbridge-native host restart --kind gateway --profile /私有目录/mac-host.json --authorization /私有目录/authorization.json
```

`render` 只生成并校验 plist。`start`、`restart` 需要授权；`stop` disable 后 bootout，避免下次登录自动恢复。固定 launchd label 为 `ai.agentbridge.gateway` 和 `ai.agentbridge.workspace-tunnel`，只使用一套进程管理器。仅登录后恢复，不承诺 FileVault 解锁前运行。

Gateway 固定绑定回环；隧道使用严格 host key、BatchMode、ExitOnForwardFailure 和 keepalive，服务器仅监听回环。发现不属于已验证 Gateway 的监听者会拒绝操作，不抢占端口。安装后的 plist 字节变化时，先停用、核验并归档旧文件，再重新安装。

按内容指纹、PID/启动时间及 readiness 决定是否重启。启动前写入 pending；输入变化或预热失败时保留 pending。当前进程就绪、插件版本和冷/热预热通过后才完成验收。

## 发布

发布所需 `agentbridge.environment.v1` profile 绑定服务器 `host`、服务 `root` 以及三个 systemd unit 的外置文件路径和 SHA256。更改模块入口后须更新外置 unit 及审核哈希；仓库模板不是实际环境配置。

```sh
scripts/agentbridge-native publish --profile /私有目录/environment.json \
  --identity /私有目录/server-identity --known-hosts /私有目录/server-known-hosts --offline
```

默认计划；`--offline` 不联网并标记线上前驱未核验。正式执行添加 `--apply --host-profile ... --authorization ...`；SSH 推送还需 `--github-identity` 与 `--github-known-hosts`。身份隔离验收使用多个 `--identity-label` 和对应 `--expect-endpoint USER_SUBJECT=CLIENT_TYPE`。

发布顺序为完整验证、治理测试、复核候选与配置、上传可信 wheel、Linux 事务、条件重启、预热、TLS/readiness/MCP/备份/宿主/隧道验收，最后推送并回读提交。`--reuse-validation` 严格复用同一候选收据；`--resume` 只补已确认候选的完成与验收，不能重新安装或重启未核验宿主。

根 CA 的正常使用见[命名迁移与证书维护](./命名迁移与证书维护.md)。旧工作站流程仅用于追溯，见[平台迁移历史](../历史归档/平台迁移/苹果系统原生维护旧版-2026-10-09.md)。
