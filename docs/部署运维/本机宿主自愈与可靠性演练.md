# 本机宿主自愈与可靠性演练

当前自愈由 macOS launchd 管理，只有 Gateway 与 Workspace 隧道两项作业。配置、授权、启动和停止入口见[原生维护](./苹果系统原生维护.md)，转发边界见[反向安全隧道](./工作台反向安全隧道.md)。

## 必须保持的约束

- Gateway 唯一进程持有回环监听，不能用杀死未知进程的方式恢复。
- 生命周期操作受 POSIX 文件锁互斥；输入指纹、PID 和启动时间共同决定是否重启。
- 预热前保留 pending；失败不得清除或签发不匹配的 baseline。
- 已安装 plist 与审核配置不同则拒绝覆盖，先停止并重新审查。
- 宿主恢复不自动重放业务提交，未知结果继续走原恢复治理。

## 离线验证

```sh
scripts/agentbridge-native validate --test tests/test_native_maintenance.py --test tests/test_runtime_governance.py --test tests/test_report_recovery.py
```

这些用例验证临时状态与受控进程，不证明真实 launchd 和跨机 SSH 已恢复。

## 实机演练

在明确维护窗口记录当前配置、授权、进程和 readiness，分别演练已授权 Gateway 重启、隧道断开后的恢复、端口冲突的拒绝处理。复核当前进程的插件版本、pending 清除、服务器回环可达与 Workspace 只读调用。两个身份应保留各自会话和 Task Hub 可见范围。

用独立验收记录保存实际开始结束时间、候选版本和结果；不能将本页步骤视作已执行。原工作站守护及历史演练见[原自愈流程快照](../历史归档/平台迁移/本机宿主自愈与可靠性演练旧版-2026-10-09.md)。
