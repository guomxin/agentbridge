## 3. 用户端与任务连续性

- 用户通过 Telegram 私聊、微信私聊或 Agent Workspace 使用系统；管理控制台面向管理员和审计员。
- Workspace 提供持久登录、可信卡片、文本/图片、任务时间线、文件交付、刷新恢复和跨端接续；消息与附件按身份隔离。
- 受理前请求持久等待，按同一幂等键恢复；受理后观察同一 run，连接中断不重新提交原请求。
- 持久任务计划支持只读汇聚和受控写终点；来源不完整时在写入前停止。取消、技能撤销和授权消费共用提交边界事务。
- 技能系统提供私有草稿、方法生成、无工具文本评测、人工审批发布、版本绑定和反馈；加载成功或评测断言通过不表示业务执行成功。
- 中央发布宿主分级、调用上下文、协调租约与恢复协议；OpenClaw 和独立 Reference Host 按共同协议接入，未声明具备 MCP Apps。
