## 3. 用户端与任务连续性

- 用户通过 Telegram 私聊、微信私聊或 Agent Workspace 使用系统；管理控制台面向管理员和审计员。
- Workspace 提供持久登录、可信卡片、文本/图片、任务时间线、文件交付、刷新恢复和跨端接续；消息与附件按身份隔离。
- 受理前请求持久等待，按同一幂等键恢复；受理后观察同一 run，连接中断不重新提交原请求。
- 持久任务计划支持只读汇聚和受控写终点；来源不完整时在写入前停止。取消、技能撤销和授权消费共用提交边界事务。
- 技能系统提供私有草稿、方法生成、无工具文本评测、人工审批发布、版本绑定和反馈；加载成功或评测断言通过不表示业务执行成功。
- 中央发布宿主分级、调用上下文、协调租约与恢复协议；OpenClaw 和独立 Reference Host 按共同协议接入，未声明具备 MCP Apps。

对应设计见[任务计划](./架构设计/通用持久化任务计划与跨系统编排详细设计.md)、[技能二期](./架构设计/业务技能质量与持续沉淀二期设计.md)
及[工作台可靠投递](./架构设计/工作台请求受理前可靠投递详细设计.md)。具体能力与实机证据不从上述功能摘要反推。

## 4. 当前部署

维护目标为 macOS 开发及本机宿主、Linux 中心服务及 CI。用户已取消后续 Windows 使用，旧 Windows 脚本与验收记录只保留历史含义。

| 入口 | 当前用途 |
| --- | --- |
| Linux `10.10.50.213:8780` | 可信认证、字段和授权卡片 |
| `8781` | 按挑战开放的 noVNC |
| `8782` | 管理控制台 |
| `8783` | Agent Workspace |
| `8790` | Streamable HTTP MCP |

macOS OpenClaw Gateway 与反向 SSH 隧道由用户级 launchd 管理，中心端经回环 `127.0.0.1:18789` 连接宿主。
SSH 保持主机密钥核验；程序、插件或环境变化按内容指纹触发必要重启，文档修改不触发部署或重启。
运行手册、版本切换和恢复边界分别见[当前内网部署](./部署运维/当前内网部署.md)、
